STOCKSENSE DESIGN SYSTEM

Brand
Name: StockSense
Tagline: Adaptive Inventory. Intelligent Fulfillment.
Visual personality: operational, technical, intelligent, enterprise, trustworthy

Colors
Primary: #38BDF8
Success: #22C55E
Warning: #F59E0B
Danger: #F43F5E
Background: #08111F
Surface: #0F1B2D
Surface elevated: #13233A
Primary text: #F8FAFC
Secondary text: #CBD5E1
Muted: #94A3B8

Do not use:
rose/pink as brand primary
red as main brand color
overly colorful dashboards
excessive gradients
excessive glassmorphism
giant hero text
decorative split-screen login
draggable login layouts

Typography
Recommended: Inter for interface text.
Optional: IBM Plex Mono for: SKU, barcode, warehouse codes, shipment IDs, task IDs
Use monospace selectively.

Radius
Cards: 14px
Inputs: 10px
Buttons: 10px
Pills: 9999px

Shadows
Use subtle shadows.
Prefer: 0 12px 40px rgba(0,0,0,.18) over heavy visual shadows.

Grid
8px spacing system.
Common values: 8, 12, 16, 24, 32, 40, 48, 64

Motion
Use Framer Motion.
Transition: 180–300ms for normal interactions. 400–700ms for major transitions.
Never animate everything.
Use motion to communicate: state changes, system activity, route movement, scanner events, success, errors, loading, navigation

Authentication Animation
Background: warehouse floor grid
foreground: small moving inventory nodes
routes: thin animated paths
system indicators: small status pulses
Animation should remain behind the authentication interface.

Accessibility
Support: keyboard navigation, focus states, reduced motion, readable contrast, screen reader labels, error announcements, semantic HTML, appropriate touch target sizes
